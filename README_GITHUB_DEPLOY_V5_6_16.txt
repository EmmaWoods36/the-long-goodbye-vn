THE LONG GOODBYE — V5.6.16 CLEAN GITHUB DEPLOY PACK

Use this clean pack for GitHub Pages.

WHAT TO UPLOAD / REPLACE
1. Replace your repository's index.html with the index.html in this folder.
2. Replace your repository's assets folder with the assets folder in this folder.
3. asset_manifest_v5_6_16.csv is for tracking only. You do not need it for the game to run.
4. the_long_goodbye_index_v5_6_16_content_polish.txt is a phone-friendly copy of the same HTML code.

WHY THIS CLEAN PACK EXISTS
The earlier full zip included backups, patches, README files, and nested historical folders.
That is useful for archiving, but confusing for GitHub upload.

This clean pack keeps the important deploy files at the top level:
- index.html
- assets/
- asset_manifest_v5_6_16.csv
- README_GITHUB_DEPLOY_V5_6_16.txt
- the_long_goodbye_index_v5_6_16_content_polish.txt

PHONE / GITHUB APP OPTION
If you are editing from your phone and cannot upload the whole folder easily:
- Open the TXT file.
- Copy all text.
- Paste it over your GitHub index.html contents.
- The assets folder still needs to exist in your repo with the matching files, or images will not show.
